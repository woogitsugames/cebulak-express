# Store assets — katalog roboczy

Ten folder nie zawiera jeszcze obrazów gotowych do publikacji. Po scaleniu grafik i funkcji z zadań 05–10, 11, 14, 18 wykonaj z działającej gry rzeczywiste przechwycenia i dodaj 8 plików PNG 1080×1920 zgodnie z `docs/sklep/zrzuty.md`.

## Kontrole eksportu

- 1080×1920, 9:16, PNG **RGB**, sRGB, bez alfa.
- Nie nakładać wymyślonych wyników, ocen, interfejsu ani nowych teł.
- Pierwsze trzy kadry pokazują realny gameplay / wybór kraju.
- Przed dodaniem każdego obrazu uzupełnić `ASSETS.md`: wersja builda, metoda, prawa/licencja.
- Nie przenosić `play-feature-1024x500.png` ani ikon: to własność zlecenia 10 w `public/assets/brand/`.

**Pliki docelowe (w kolejności prezentacji):** `01-jeden-dotyk.png`, `02-z-osmiu-krajow.png`, `03-bagaz-na-dachu.png`, `04-sloiki-i-paczki.png`, `05-po-drodze-do-domu.png`, `06-liga-polonii.png`, `07-wyzwanie-dnia.png`, `08-udostepnij-wynik.png`.

## Kontrola przed wydaniem

1. Obejrzeć każdy obraz jako miniaturę 180×320 i na telefonie.
2. Porównać kadr z rzeczywistym ekranem aplikacji; poprawić opis, jeśli się różni.
3. Sprawdzić zakazane symbole, realne marki i nazwy konkurencyjnych gier.
4. Potwierdzić, że funkcje w zrzutach są wdrożone i można je odtworzyć na urządzeniu.
