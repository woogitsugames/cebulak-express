## 5. Jak sprawdzać (przed każdym PR)
```
npx tsc --noEmit && npx tsc --noEmit -p tsconfig.e2e.json && npx vitest run && npm run build
npx playwright test --project="Desktop 1280x800 (Chromium)" --project="Pixel 7 (Chromium)" --workers=2
for i in 1 2 3; do npx playwright test --project="Slow 4G + CPU 4x (Chromium)"; done
```
- WebKit (iPhone) nie działa lokalnie — weryfikuje go CI na GitHubie.
- Nie przebudowuj `dist` w trakcie testów Playwright (daje fałszywe błędy konsoli). Nie zostawiaj `vite preview` na porcie 4173 (Playwright użyje starego builda przez `reuseExistingServer`).
- `public/licencje.html` regeneruje `prebuild` — commituj świadomie.
