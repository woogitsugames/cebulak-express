Muzyka — odsłuch

Autorska pętla 32 taktów (2/4), wariant świąteczny ze zwolnionym tempem i dzwoneczkami oraz 16 autorskich akcentów granicznych. Akcenty można odtwarzać oddzielnie lub nad pętlą.

Akcenty przy przekraczaniu granicy

Wybierz kraj, by usłyszeć krótki motyw (każdy poniżej 3 sekund). Kolejne kliknięcie zastąpi poprzedni akcent.

Odtwarzacz gotowy

Uruchom przez npm run dev i otwórz /tools/music-demo.html. Przeglądarka odblokowuje Web Audio dopiero po geście użytkownika. W tle karty dźwięk zostaje wyciszony. Wszystkie melodie i brzmienia są generowane lokalnie, bez plików audio ani bibliotek.
