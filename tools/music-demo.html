Muzyka — odsłuch

Autorska pętla polkowa (32 takty, 2/4, 124 BPM). Wybierz aranżację i uruchom odtwarzanie. Świąteczna wersja ma dodatkowe dzwoneczki.

Odtwarzacz gotowy

Przeglądarka odblokowuje Web Audio dopiero po geście użytkownika. Przełączenie karty w tło wstrzymuje odtwarzanie. Demo działa w Vite: npm run dev → /tools/music-demo.html.
