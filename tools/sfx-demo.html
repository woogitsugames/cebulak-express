Efekty dźwiękowe — odsłuch

Wszystkie dźwięki powstają na żywo w Web Audio. Naciśnij dowolny przycisk, aby odblokować audio i posłuchać efektu. Na telefonie można sprawdzić także wibracje.

Uruchom npm run dev w katalogu projektu, a następnie otwórz /tools/sfx-demo.html. Przeglądarki bez Web Audio lub obsługi wibracji pomijają niedostępne efekty.
